# Setup observations

29 October 2026, P0. These are observed setup results, not evaluation metrics.

| Service | What was tried | Observed result | Improvement to request |
| --- | --- | --- | --- |
| Decionis AgentSafe | Add SiteWork using the already open workspace | The current gateway is Clasp. The deployed API source keeps a unique gateway reservation per organization, and the fleet provisioner rejects a second tenant with `WORKSPACE_ALREADY_DEPLOYED`. | Support explicit selection and creation of multiple gateways in one workspace, preserving separate credentials and ownership proofs. |
| Decionis AgentSafe operator CLI | Read the live tenant list | The local CLI refused because it expected one vault in `agentsafe-rg` and found two. Kubernetes ExternalSecrets listing was denied to the current identity. | Update operator discovery for dedicated enforcement vaults and document the required read/provisioning roles. |
| Decionis AgentSafe dci fallback | Use the existing gateway after the user's explicit selection | The existing local ingress key matched the active registry. Health and workspace authentication through dci returned HTTP 200 and `PASSTHROUGH`. The workspace API key was also verified directly. | Make the distinction between ingress keys, workspace keys, health, and policy verification clear in onboarding. |
| Azure Key Vault | Retrieve the dci workspace API key | CLI sign-in and subscription ownership did not provide secret-read access. A user-approved temporary grant on the single secret allowed retrieval; the exact grant was then removed and its absence verified. | Document the minimum secret-scoped permission separately from subscription ownership and CLI sign-in. |
| Nebius Token Factory | Enter the public hackathon activation code in the billing promo-code field | Rejected as an invalid promo code. The official promotion form accepted the activation code and confirmed that it will email a separate redemption code. | Clearly distinguish activation codes from redeemable billing promo codes on the event resources page. |
| Nebius Builders Program | Inspect the existing application | Email confirms review is pending and an update is expected within two business days. | Display application and credit-issuance status in the account console. |
| Nebius AI Cloud | Inspect available hackathon offers, the existing compute-grant application, and billing | The hackathon FAQ has no separate published AI Cloud credit grant. A separate compute-grant application is awaiting review. Billing setup would charge $25 to activate; it was not submitted. | Show the expected grant-review timeline and whether hackathon GPU workloads qualify. |
| Tavily | Create and verify a free account, then run SiteWork's existing allowlisted search | The Researcher plan provides 1,000 monthly credits with pay-as-you-go off. The default API key authenticated successfully; the live search returned three OSHA results. The additional $25 Builders credit is still pending program approval. | No Tavily API issue observed in this setup check. |
| Decionis execution authority (via dci) | Call the authority with the `DecionisAuthorityRequest` shape from `@decionis/sdk-node` 0.1.0 | `POST /v1/authority/evaluate` and `/v1/authority/enforce` return 404 "Route not found". `/v1/authority/enforce-and-bind` exists but requires an Agent-Safe Intent v1 binding (`protocol_version`, `intent_id`, `captured_at`, `expires_at`, `intent_hash`, mode `SHADOW`/`PARALLEL`/`ENFORCEMENT`), not the SDK's typed shape. | Align `@decionis/sdk-node` types and routes with the deployed authority, or mark the old routes as removed. |
| Decionis execution authority (via dci) | Send the intent with an `Idempotency-Key` header equal to `context.idempotency_key` | 400 `AUTHORITY_IDEMPOTENCY_KEY_MISMATCH` although both values were identical. Without the header the same request succeeded. | Accept a matching header, or document that intents must not carry one. |
| Decionis protocol API (via dci) | Probe `POST /v1/protocol/evaluate-decision` with an empty JSON body to learn its required fields | 200 with `verdict: ALLOW`, `outcome: APPROVE`, `authority_classification: OBSERVATIONAL`, instead of a validation error. | Reject a request without `decision_type` instead of approving it. |
| Decionis policy (dci tenant) | One SHADOW integration intent with no measurements, no citations and an evidence error | `ALLOW` with `POLICY_MATCHED, POLICY_ACTION_AUTO_APPROVE`. The tenant's default policy auto-approves this action type. | Default unknown action types to ESCALATE until a policy names them. |
| NVIDIA Cosmos Transfer 2.5 (docs and source at `2ff49d0`, not yet run on a GPU) | Plan a distilled-edge batch from the repo's `docs/inference.md` | The docs say to pass `--model=edge/distilled`, but `cosmos_transfer2/config.py` only registers that checkpoint when `COSMOS_EXPERIMENTAL_CHECKPOINTS=1`, and the docs don't mention the variable. Inference keeps the input frame rate, so frame rate directly sets the chunk count and runtime; the docs don't say so. The timing table covers H100 NVL/PCIe but not H100 SXM, which is what Nebius offers. The repo now redirects to Cosmos 3 and receives only limited maintenance. | Document the experimental-checkpoint flag next to the distilled command, state the frame-rate behaviour, and publish H100 SXM timings. |
| Decionis policy authoring | Add policy write access for SiteWork | The dci runtime key is MEMBER and cannot manage keys; AgentSafe also deliberately rejects policy write privileges on a runtime key. An existing authorized operator command issued a separate MEMBER key with exactly `policy:read` and `policy:write`. Live authentication verified it for dci and verified that the original runtime key still works. No owner-mailbox access or additional Azure role grant was needed. The SiteWork policy itself still needs to be loaded. | Offer a clear authoring-key workflow separate from the gateway runtime credential. |
| AWS GPU quota | Request a Cosmos fallback in Stockholm | EC2 reports `p5.4xlarge` with one 80 GiB H100 and 16 vCPUs, offered in `eu-north-1` with On-Demand and Spot support. Both applied P quotas were zero. Requests for 16 vCPUs each were submitted and reached `CASE_OPENED`; approval and capacity remain pending. | Show regional quota lead times before users prepare a GPU workload. |
| Tavily Research | Start a research task with a JSON Schema `output_schema` (`type: object` at the top) | 400 "Output schema contains unexpected keys: type. Only 'properties' and 'required' are allowed." The SDK docstring only says "Schema for the 'structured_output' response format (JSON Schema dict)". Without `type`, the task completed in 49 s with structured findings. | State the accepted schema subset in the SDK docstring and API reference. |
| Tavily Map / Crawl / Extract | Build US and SE packs from allowlisted seeds with `select_domains` regexes | Worked as documented: the US trench seeds mapped 20 URLs and read 12 pages; the SE trench seeds read 25 av.se pages; one PDF seed (Svenskt Trä) was extracted directly. | No issue observed. |
| Decionis execution authority (via dci) | Send a `policy.update` intent in ENFORCEMENT mode with the runtime key | 403 "API key missing required scope. Need one of: decision:write, decision:*, org:*, decision:enforce". SHADOW mode with the same key and the same body works. | State the per-mode scope requirement on `enforce-and-bind` in the OpenAPI description. |
| Decionis dossier | Read the proof packet of a SiteWork construction decision | `dossier_type` is `FINANCE_ROUTING_DECISION_DOSSIER_V1` and `routing_decision.decision_domain` is `FINANCE` for `inspection.release_hold`. The signatures verify offline (`@decionis/verify` 0.5.0) and a one-byte change fails as expected. | Classify decision domains for non-finance action types instead of defaulting to FINANCE. |

Time lost has not been measured. No performance figures or model capability claims have been inferred from these observations.
